PASSIVE RECEIVED-BLOCK INSPECTOR -- DRAFT FOR CONTENT REVIEW
Purpose: extend raw TCP framing confidence with exact inspected host body normalization and expected-index validation, using bytes already received offline. No network, sender, hardware mode, firmware/update, camera profile selection or image decoder. Scope of source evidence remains pinned host mode2 and inspected ec8l producer; no universal camera claim.
Proposed pure API inspectReceivedBlock(bytes,{expectedIndex}) accepts Buffer/Uint8Array and explicit unsigned32 expected index. No implicit fresh-session value. Input/view must be copied and never mutated or retained through aliases. Wrong API types/ranges throw TypeError under local policy.
Body length must be20..16000. Invalid complete body returns a documented rejection; body framing header has already been removed. A normal16000-byte body has last12 bytes: producerMetadataRaw at15988, index at15992, inverseWordRaw at15996, unsigned32 little-endian. Metadata is opaque; do not call it checksum, time or session ID.
For short length L, snapshot its last12 bytes, relocate them to fixed offsets15988..15999, and if L<=15996 write zero to original trailer start L-12 through L-9. For15997..15999 skip the zero write. Copy overlap must preserve the original last12 bytes. Compare all32 actual index bits to explicit expectedIndex. Mismatch returns rejection and no normalized segments. A matching index only proves this transport acceptance condition, not valid records/image/time or end-of-capture.
Represent only known normalized bytes. Return nonoverlapping maximal contiguous segments {offset,bytes}; unknown padding is absent and explicitly listed as unknown ranges. Unknown bytes must not be fabricated as known zeros. Known bytes are original received bytes plus the relocated trailer and conditional zero write, with relocation overwrites taking precedence. Original unfilled positions are unspecified. For L<15988 the gap L..15987 remains unknown; for L>=15988 the normalized body is fully known. Output byte buffers detached.
Expose raw metadata/index/inverse, received length, next index modulo32 and an explicit wrapUnverified flag when index was4294967295. Inverse consistency is an observation only: the inspected TCP host checks index equality but does not reject solely for inverse mismatch. Do not silently add that as a claimed vendor acceptance rule. A short body is not an EOF/last-block indicator; return no capture-complete claim.
Tests should cover full/short/minimum bodies, boundary lengths15984..16000, overlap cases15997..15999, exact old-trailer zero placement, preserved index/inverse, mismatched/duplicate/gap indices, arbitrary explicit initial index, mechanical wrap with unverified end-to-end meaning, unknown padding never treated as known, input/output detachment and after-call input changes. Authored examples are not camera images. Production cannot read fixtures or original source.
This is an unreleased draft. Source investigator must review body offsets, relocation/zero rules, known-range representation and the acceptance/metadata scope before isolated implementation.
