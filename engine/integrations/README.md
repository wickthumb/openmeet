# Independent backend protocol helpers

Imported from `OpenMeet-Implementation-Handoff-20261031.zip`, supplied by the
user as independently authored backend work. `IMPORT.json` records the archive
hash, selected file hashes and integration changes. The `protocol-core` directory
preserves the modules' relative imports. It contains Node built-ins only.

The ESM API is `index.js`. See [network camera integration](../../docs/network-camera.md)
for the camera service, CLI, current limitations and other helper namespaces.
Protocol fixtures are invented offline examples. Original binary artifacts,
intermediate proof machinery, old UI code and private data are not included.
